Workflow.
This application should run locally or in a local server.
When User runs this application first time - User must create an account by providing username and password.
If User account already exists - User forwards to Login page and User provides username and password.
This application consists of .Net Web API back-end and Angular front-end.

Create the Registration page and Login page in Angular.
When application loads first time it makes a request to api/user/is-created and gets { isCreated = [ false | true ] }.
