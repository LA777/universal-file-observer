## Transaction Handling

```
START TRANSACTION
    ?
SAVEPOINT Operations
    ?? PC insert/select
    ?? StorageDrive insert/select
    ?? Volume insert/select
    ?? Snapshot insert
    ?? VolumeInfo insert
    ?? Folder tree processing
    ?? All dependent inserts
    ?
SUCCESS? 
    ?? YES ? COMMIT (all changes persisted)
    ?? NO  ? ROLLBACK (all changes discarded)
```

## Performance Characteristics

```
Operation              Time Complexity    Notes
??????????????????????????????????????????????????????
Insert snapshot          O(n)             n = folders + files
Get snapshot by ID       O(1)             Direct key lookup
Get all snapshots        O(m)             m = snapshots
Search files             O(log n)         Indexed by name
Find duplicates          O(n log n)       Full scan needed
Delete snapshot          O(n)             Cascades to related
```

Where: n = total entities, m = snapshots
